## 完成后的能力边界

最终版本会具备：按消息来源识别主人、当前群管理员和普通群员；按“身份 + 群 + 工具 + 风险等级”决定能否调用工具；由主 Agent 选择直接回答或拆分给受限 SubAgent；踢人执行二次确认，禁言、解禁和发消息直接走权限、额度和审计；支持提醒、暂停/恢复/取消、失败重试、文件读取和受限网页读取；配置可备份回滚，发布经过 CI 和故障检查。默认策略仍保持低频参与，任何高风险能力都不会因为模型的一句话直接执行。
