## 完成后的能力边界

最终版本会具备：按消息来源识别主人、当前群管理员和普通群员；按“身份 + 群 + 工具 + 风险等级”决定能否调用工具；由主 Agent 选择直接回答或拆分给受限 SubAgent；对删除、踢人、发文件、外部写入等动作执行二次确认；记录最小必要审计信息并应用冷却、每日额度、并发和步骤上限；支持可暂停的后台任务、失败重试、超时和安全停止。默认策略仍保持低频参与，任何高风险能力都不会因为模型的一句话直接执行。
