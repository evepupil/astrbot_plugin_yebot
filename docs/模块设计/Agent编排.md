# Agent 编排

- 模块定位：让主 Agent 负责理解和路由，让受限 SubAgent 负责单一领域的小任务。
- 对应代码：预留 `yebot/runtime/agents/`
- 所属里程碑：[M5](../roadmap.md#m5)
- 当前状态：未开始
- 最近更新时间：2026-07-31

## 职责与边界

主 Agent 不绕过权限和工具网关；SubAgent 不自行扩权、不直接对外发消息。

## 结构与数据流

消息摘要 -> 主 Agent -> 任务计划 -> 受限 SubAgent/工具 -> 结果汇总 -> 确认/回复。

## 关键决策

限制最大步骤、最大并发、总超时和上下文大小；每一步必须能说明输入来源和输出用途。

## 当前实现

AstrBot 当前 SubAgent 编排未启用，插件尚未注册 Agent。

## 验证方式

用固定任务测试直接回答、单工具、串行多工具、失败重试和步骤上限。

## 待扩展项

增加任务队列、暂停/恢复、人工接管和跨消息任务状态。
