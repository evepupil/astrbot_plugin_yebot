# 发布与安全

- 模块定位：把 YeBot 从个人测试插件推进到可回滚、可审计的稳定部署。
- 对应代码：发布脚本与配置说明，后续补充 `scripts/`
- 所属里程碑：[M8](../roadmap.md#m8)
- 当前状态：未开始
- 最近更新时间：2026-07-31

## 职责与边界

覆盖秘密管理、配置备份、依赖升级、权限审计、故障演练、日志脱敏和回滚。

## 结构与数据流

Windows 源码检查 -> 插件同步 -> 容器加载 -> 健康检查 -> 人工验收 -> 版本记录。

## 关键决策

不把密钥、QQ 登录态或运行时数据库提交到仓库；部署失败必须能恢复上一份插件目录。

## 当前实现

当前仓库已设置 `.gitignore` 和 LF 换行规则，部署仍由人工执行。

## 验证方式

执行格式、静态分析、单测、插件导入、容器加载和回滚演练。

## 待扩展项

增加 CI 门禁、签名发布包、自动备份和运行指标。

- 2026-07-31：建立正式发布和安全边界。
