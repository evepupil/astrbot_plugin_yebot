# 发布与安全

- 模块定位：把 YeBot 从个人测试插件推进到可回滚、可审计的稳定部署。
- 对应代码：`yebot/runtime/release/`、`scripts/`、`.github/workflows/quality.yml`
- 所属里程碑：[M8](../roadmap.md#m8)
- 当前状态：进行中
- 最近更新时间：2026-08-02

## 职责与边界

覆盖秘密管理、配置备份、依赖升级、权限审计、故障演练、日志脱敏和回滚。

## 结构与数据流

Windows 源码检查 -> 插件同步 -> 容器加载 -> 健康检查 -> 人工验收 -> 版本记录。

## 关键决策

不把密钥、QQ 登录态或运行时数据库提交到仓库；部署失败必须能恢复上一份插件目录。

## 当前实现

`ConfigBackup` 对 JSON 配置做原子备份和恢复；`AuditLogWriter` 输出脱敏 JSONL；`RuntimeMetrics` 提供工具和任务计数；`scripts/release_check.ps1` 与 GitHub Actions 执行测试、Ruff 和 strict mypy；`scripts/sync_plugin.ps1` 负责 Windows 源码到 WSL 插件目录的增量同步，并提供显式重启开关。

## 验证方式

执行格式、静态分析、单测、插件导入、容器加载、配置回滚、同步和重启演练。

## 待扩展项

增加签名发布包、自动备份策略、容器健康探针和正式运行指标上报；当前 CI、备份、脱敏审计和本地指标已具备。

## 改动历史

- 2026-07-31：建立正式发布和安全边界。
- 2026-08-02：实现备份回滚、脱敏审计、运行指标、CI 门禁和 WSL 同步脚本。
