# 工具包与后台任务

- 模块定位：在权限和审计基础上提供查询、提醒、文件/网页任务与可暂停后台作业。
- 对应代码：`yebot/runtime/tools/`、`yebot/runtime/jobs/`、`yebot/runtime/forwarding/`
- 所属里程碑：[M7](../roadmap.md#m7)
- 当前状态：进行中
- 最近更新时间：2026-08-03

## 职责与边界

工具包只承载清晰、可测试的能力；后台任务必须有所有者、作用域、状态和取消方式。

## 结构与数据流

提醒请求 -> 主人提醒意图解析（可解析时直达） -> M4/M6 网关 -> 任务记录
-> 调度/执行 -> QQ 通知。

虚构转发请求 -> 主 Agent 生成对话草稿 -> 节点校验与 `（虚构）` 标记 -> M4/M6 网关
-> OneBot 合并转发。普通用户仍由主 Agent 选择提醒工具，所有执行都经过网关。

## 关键决策

文件和网页工具默认只读并限制在配置根目录/公开 HTTP(S)；提醒任务有所有者和群作用域，成员只能管理自己的任务，群管理员和主人可管理当前群任务。虚构转发仅主人可用，目标可通过 @、回复、人名、QQ 号或指代词交给[目标解析](目标解析.md)，每个节点都由工具统一追加 `（虚构）`，不使用目标的真实 QQ 号。重试使用次数上限和指数退避，避免群消息刷屏。

## 当前实现

已实现 `reminder.create/list/cancel/pause/resume`，JSON 存储采用临时文件加原子替换。`JobScheduler` 提供到期执行、暂停/恢复、取消、失败重试和指数退避。`runtime/jobs/intent.py` 解析带相对时间的中文提醒命令，支持秒、分钟、小时、天、周和单个 @ 目标，也会保留非 @ 的目标文本。主人命令在 LLM 请求前直达 `reminder.create`，名字或指代词会先由[目标解析](目标解析.md)验证成唯一成员，再写入到期消息的 QQ @；缺时间、内容或唯一目标时直接提示补充，避免被聊天人设拦截。

`message.forward_scene` 接收模型生成的 3 到 12 条 `speaker/content` 草稿；`speaker=target` 会被替换为当前群中已解析成员的昵称，其余 speaker 也统一追加 `（虚构）`。节点只允许纯文本，拒绝 CQ 码和任意原始 OneBot 段；写入时调用 `send_group_forward_msg`，仍受发送额度、审计、幂等和 dry-run 约束。OneBot 运行适配器还提供 `file.read` 和 `web.fetch`，文件路径不能越过配置根目录，网页请求拒绝本地和私网地址。后台循环在首次工具请求后启动，插件终止时取消。

## 验证方式

单测覆盖提醒意图解析、虚构转发节点标记与边界、主人权限、OneBot 合并转发 payload、任务创建、取消、暂停/恢复、成员作用域、重试退避、最终失败、JSON 重启恢复、文件根目录保护和私网 URL 拒绝；真实容器还需验证提醒和合并转发消息到达。

## 待扩展项
