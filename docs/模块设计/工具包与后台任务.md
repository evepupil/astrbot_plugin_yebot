# 工具包与后台任务

- 模块定位：在权限和审计基础上提供查询、提醒、文件/网页任务与可暂停后台作业。
- 对应代码：预留 `yebot/runtime/tools/`、`yebot/runtime/jobs/`
- 所属里程碑：[M7](../roadmap.md#m7)
- 当前状态：未开始
- 最近更新时间：2026-07-31

## 职责与边界

工具包只承载清晰、可测试的能力；后台任务必须有所有者、作用域、状态和取消方式。

## 结构与数据流

用户请求 -> 任务记录 -> 调度/执行 -> 进度摘要 -> QQ 通知；执行仍经过 M4/M6 网关。

## 关键决策

默认只读，写入和外发动作逐项确认；重试使用上限和退避，避免群消息刷屏。

## 当前实现

尚未开始。

## 验证方式

测试任务创建、取消、重试、超时、重启后状态和权限变更。

## 待扩展项

增加定时规则、队列持久化和多群任务隔离。
