# 工具包与后台任务

- 模块定位：在权限和审计基础上提供查询、提醒、文件/网页任务与可暂停后台作业。
- 对应代码：`yebot/runtime/tools/`、`yebot/runtime/jobs/`
- 所属里程碑：[M7](../roadmap.md#m7)
- 当前状态：进行中
- 最近更新时间：2026-08-03

## 职责与边界

工具包只承载清晰、可测试的能力；后台任务必须有所有者、作用域、状态和取消方式。

## 结构与数据流

用户请求 -> 主人提醒意图解析（可解析时直达） -> M4/M6 网关 -> 任务记录
-> 调度/执行 -> QQ 通知。普通用户仍由主 Agent 选择提醒工具，所有执行都经过网关。

## 关键决策

文件和网页工具默认只读并限制在配置根目录/公开 HTTP(S)；提醒任务有所有者和群作用域，成员只能管理自己的任务，群管理员和主人可管理当前群任务。重试使用次数上限和指数退避，避免群消息刷屏。

## 当前实现

已实现 `reminder.create/list/cancel/pause/resume`，JSON 存储采用临时文件加原子替换。`JobScheduler` 提供到期执行、暂停/恢复、取消、失败重试和指数退避。`runtime/jobs/intent.py` 解析带相对时间的中文提醒命令，支持秒、分钟、小时、天、周和单个 @ 目标；主人命令在 LLM 请求前直达 `reminder.create`，缺时间或内容时直接提示补充，避免被聊天人设拦截。OneBot 运行适配器增加 `file.read` 和 `web.fetch`，文件路径不能越过配置根目录，网页请求拒绝本地和私网地址。后台循环在首次工具请求后启动，插件终止时取消。

## 验证方式

单测覆盖提醒意图解析、任务创建、取消、暂停/恢复、成员作用域、重试退避、最终失败、JSON 重启恢复、文件根目录保护和私网 URL 拒绝；真实容器还需验证提醒消息到达。

## 待扩展项

增加 cron/重复规则、队列化执行和任务进度消息；当前已按群和所有者隔离任务。
