# 工具网关

- 模块定位：为所有工具提供统一声明、参数校验、权限检查、超时和错误包装。
- 对应代码：预留 `yebot/runtime/tools/`
- 所属里程碑：[M4](../roadmap.md#m4)
- 当前状态：未开始
- 最近更新时间：2026-07-31

## 职责与边界

工具网关是唯一允许工具执行的入口。Agent 不直接持有 QQ、文件系统或网络客户端。

## 结构与数据流

工具目录 -> 参数校验 -> 身份/作用域检查 -> 风险级别检查 -> 二次确认 -> 执行器 -> 结果脱敏。

## 关键决策

每个工具必须声明名称、用途、参数 schema、所需角色、风险等级、超时和是否可撤销。

## 当前实现

尚未开始，仅完成路线图和边界文档。

## 验证方式

覆盖未知工具、参数错误、越权、超时、重复执行和异常返回。

## 待扩展项

增加插件式工具发现、沙箱执行和按群启停。

## 改动历史

- 2026-07-31：建立统一工具网关设计边界。
