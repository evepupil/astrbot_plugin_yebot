# 工具网关

- 模块定位：为所有工具提供统一声明、参数校验、权限检查、超时和错误包装。
- 对应代码：`yebot/runtime/tools/`
- 所属里程碑：[M4](../roadmap.md#m4)
- 当前状态：已完成
- 最近更新时间：2026-08-03

## 职责与边界

工具网关是唯一允许工具执行的入口。Agent 不直接持有 QQ、文件系统或网络客户端；平台适配器只负责把已授权的工具声明注册到网关。

## 结构与数据流

工具目录 -> 工具查找 -> 身份/作用域检查 -> 参数校验 -> 确认/额度/目标保护 -> 超时执行 -> 统一结果。

工具注册与执行分开：`ToolDefinition` 只保存名称、用途、权限键、参数 schema、风险和超时；`ToolRegistry` 保存声明与异步 handler；`ToolGateway` 是唯一调用入口。执行上下文包含身份、有效目标群和请求 ID，handler 不需要重新推断调用者身份。

## 关键决策

每个工具必须声明名称、用途、权限键、参数 schema、风险等级和超时。权限键可以按工具拆分，例如 `group.member.kick` 与 `group.member.mute`；工具也可以通过 `permission_policy` 提供独立角色覆盖。当前只有 `group.kick_member` 进入确认门，禁言、解禁和发消息直接执行并受额度、审计和目标保护约束。

## 当前实现

已实现：`ToolDefinition`、`ParameterSpec`、`ToolRegistry` 和 `ToolGateway`。网关会拒绝未知工具、未知权限、角色不足、越过当前群和缺少群号的请求；参数只接受声明的 JSON-like 类型，不做隐式转换；handler 受单工具超时限制，异常只返回稳定错误类型，不泄漏异常正文。

`catalog.py` 已声明群成员、最近发言人、随机普通成员、群管理、发消息、提醒、文件读取、网页读取、表情收藏/检索/发送和记忆读写工具。`onebot.py` 通过事件的 `bot.api.call_action` 注册 QQ action；最近发言人通过 `get_group_msg_history` 返回去重后的候选，随机成员会排除当前操作者、机器人、群主和管理员。禁言时长允许省略，工具使用 60 秒短时兜底，模型传入的时长仍受上限校验。提醒由 `JobScheduler` 持久化和执行，文件读取限制在配置根目录，网页读取拒绝本地/私网地址，表情发送只使用当前群的稳定 ID，并优先发送 NapCat 原生 `mface`，失败时回退图片。`ToolGateway` 复用 M6 `GuardrailManager`，提供一次性踢人确认、幂等缓存、每日额度、并发限制、目标保护和统一错误结果；`main.py` 的所有 Agent/function tool 都经过同一入口。

群管理 function tool 会从当前 OneBot 消息的 At 段提取唯一的非机器人目标，并优先覆盖模型猜测的 `user_id`。At 出现在动作词前、时长前或消息末尾都使用同一目标；多个目标 At 会拒绝自动选择，避免静默操作错误成员。旧版 CQ 文本格式也支持同样的提取规则。

At 不是群管理工具的必填条件。没有 At 时，主 Agent 可以依据当前对话中的人名、QQ 号、回复对象和指代词推断目标；只有候选冲突或完全没有线索时才追问。OneBot 写入 action 的成功结果会回传脱敏后的 `params`，让 Agent 能明确复述实际操作目标和时长。

## 验证方式

`tests/test_tools.py`、`tests/test_onebot_tools.py`、`tests/test_guardrails.py`、`tests/test_jobs.py`、`tests/test_release.py` 和 `tests/test_memory.py` 覆盖工具注册、最近发言人查询、随机候选排除、禁言默认时长、参数错误、权限作用域、记忆范围、版本替换、软删除、确认过期/串用、额度、幂等、目标层级保护、提醒重试、文件根目录和脱敏审计。当前本地全量测试、Ruff 和 strict mypy 均通过；运行态工具注册、QQ action、提醒到达和踢人确认仍需人工验收。
