# 工具网关

- 模块定位：为所有工具提供统一声明、参数校验、权限检查、超时和错误包装。
- 对应代码：`yebot/runtime/tools/`、`yebot/runtime/targeting/`（见[目标解析](目标解析.md)）
- 所属里程碑：[M4](../roadmap.md#m4)
- 当前状态：已完成
- 最近更新时间：2026-08-03

## 职责与边界

工具网关是唯一允许工具执行的入口。Agent 不直接持有 QQ、文件系统或网络客户端；平台适配器只负责把已授权的工具声明注册到网关。

## 结构与数据流

工具目录 -> 工具查找 -> 身份/作用域检查 -> 参数校验 -> 确认/额度/目标保护 -> 超时执行 -> 统一结果。

工具注册与执行分开：`ToolDefinition` 只保存名称、用途、权限键、参数 schema、风险和超时；`ToolRegistry` 保存声明与异步 handler；`ToolGateway` 是唯一调用入口。执行上下文包含身份、有效目标群和请求 ID，handler 不需要重新推断调用者身份。

## 关键决策

每个工具必须声明名称、用途、权限键、参数 schema、风险等级和超时。权限键可以按工具拆分，例如 `group.member.kick` 与 `group.member.mute`；工具也可以通过 `permission_policy` 提供独立角色覆盖。当前只有 `group.kick_member` 进入确认门，禁言、解禁、发消息和消息撤回直接执行并受额度、审计和目标保护约束。

## 当前实现

已实现：`ToolDefinition`、`ParameterSpec`、`ToolRegistry` 和 `ToolGateway`。网关会拒绝未知工具、未知权限、角色不足、越过当前群和缺少群号的请求；参数只接受声明的 JSON-like 类型，不做隐式转换；handler 受单工具超时限制，异常只返回稳定错误类型，不泄漏异常正文。

`catalog.py` 已声明群成员、最近发言人、随机普通成员、群管理、发消息、消息撤回、虚构转发、提醒、文件读取、网页读取、模型排行榜、表情收藏/检索/发送和记忆读写工具。`model.ratings` 使用全角色可读的全局权限，只连接固定的 Codex Radar 公共接口，不接受模型传入的任意 URL。`message.recall` 只允许主人和当前群管理员调用，入口必须提供当前消息唯一引用的 ID；工具层先用 `get_msg` 复查消息仍属于当前群，再调用 `delete_msg`，可撤回群员或机器人自己的消息。`message.forward_scene` 的权限键只允许主人在当前群调用；工具层读取目标昵称并固定追加 `（虚构）`，仅生成 `user_id=0` 的纯文本自定义节点，拒绝由模型提供真实身份或原始消息段。`onebot.py` 通过事件的 `bot.api.call_action` 注册 QQ action；最近发言人通过 `get_group_msg_history` 返回去重后的候选，随机成员会排除当前操作者、机器人、群主和管理员。禁言时长允许省略，工具使用 60 秒短时兜底，模型传入的时长仍受上限校验。提醒由 `JobScheduler` 持久化和执行，文件读取限制在配置根目录，网页读取拒绝本地/私网地址，表情发送只使用当前群的稳定 ID，并优先发送 NapCat 原生 `mface`，失败时回退图片。`ToolGateway` 复用 M6 `GuardrailManager`，提供一次性踢人确认、幂等缓存、每日额度、并发限制、目标保护和统一错误结果；`main.py` 的所有 Agent/function tool 都经过同一入口。

所有成员目标统一交给[目标解析](目标解析.md)。唯一非机器人 @ 的优先级最高，At 可以出现在动作词前、时长前或消息末尾；其后依次使用被回复消息作者、已验证的 QQ 号、当前群名片/昵称和明确指代词对应的最近发言人。多个候选、重名或没有线索时，function tool 在进入网关前结束并返回候选说明，避免静默操作错误成员。旧版 CQ 文本格式也支持同样的 At 规则。

At 不再是群管理、提醒或虚构转发工具的必填条件。模型可以提供 `target`，也可以由适配层直接从当前原话找线索；无论入口如何，最终只有唯一 QQ 号能通过网关。OneBot 写入 action 的成功结果会回传脱敏后的 `params`，让 Agent 能明确复述实际操作目标和时长。

## 验证方式

`tests/test_tools.py`、`tests/test_onebot_tools.py`、`tests/test_targeting.py`、`tests/test_forwarding.py`、`tests/test_guardrails.py`、`tests/test_jobs.py`、`tests/test_release.py` 和 `tests/test_memory.py` 覆盖工具注册、成员目标解析、虚构节点强制标记、主人权限、合并转发 payload、消息撤回的角色、当前群和 OneBot action、最近发言人查询、随机候选排除、禁言默认时长、参数错误、权限作用域、记忆范围、版本替换、软删除、确认过期/串用、额度、幂等、目标层级保护、提醒重试、文件根目录和脱敏审计。当前本地全量测试、Ruff 和 strict mypy 均通过；运行态工具注册、QQ action、提醒到达和踢人确认仍需人工验收。
