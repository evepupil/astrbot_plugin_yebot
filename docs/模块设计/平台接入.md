# 平台接入

- 模块定位：定义 AstrBot 与 OneBot/AIOCQHTTP 的事件接入和验收边界。
- 对应代码：`main.py`、`yebot/runtime/observer.py`
- 所属里程碑：[M1](../roadmap.md#m1)
- 当前状态：进行中
- 最近更新时间：2026-07-31

## 职责与边界

只负责平台事件到插件内部摘要的转换。消息发送、模型调用和工具执行属于后续模块。

## 结构与数据流

AstrBot 先按 `AIOCQHTTP` 和 `GROUP_MESSAGE` 过滤，再由运行时检查原始 OneBot 事件的 `post_type` 与 `message_type`。`message`、`sender`、`group_id` 只用于当次解析。

## 关键决策

通知和请求事件不进入消息观察逻辑。当前适配器可能把带群号的通知包装成群消息，因此必须再次检查原始 `post_type == message`。

## 当前实现

入口已经注册 AIOCQHTTP 群消息过滤器，并调用 `observe_event` 生成脱敏摘要。入口和运行时适配器同时支持 AstrBot 插件包相对导入与本地直接导入，容器实际加载已验证通过。

## 验证方式

用纯 Python 单测覆盖消息、通知、请求三类输入；运行中的容器补做私聊往返和群聊 @ 验收。

## 待扩展项

补充私聊入口、平台能力探测和 OneBot action 错误映射。
