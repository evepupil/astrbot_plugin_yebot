# Message observation and low-frequency policy

- Module: group event filtering and deterministic participation gates.
- Code: `yebot/domain/identity.py`, `yebot/domain/policy.py`, `yebot/runtime/observer.py`, `main.py`
- Milestone: [M2](../roadmap.md#m2)
- Status: in progress
- Updated: 2026-08-02

## Responsibilities

The observer filters OneBot group messages and produces a redacted observation.
The normal reply policy handles mention requirements, quiet hours, cooldown,
daily quota, probability, and observe-only mode. It never stores the raw message.

The sticker reaction path uses a separate `LowFrequencyPolicy` instance. It does
not require an @ mention and has its own probability, cooldown, quiet hours, and
daily quota. This keeps occasional sticker reactions independent from normal
conversation replies.

## Data flow

```text
raw group event -> observe_event -> identity + mention -> normal reply policy
                                      |
                                      +-> sticker send policy -> background agent
```

Policy state is held in memory by group and date. A quota is consumed only by an
explicit `commit` after a real send; an agent decision or dry-run does not consume
it. `observe_only=true` disables all automatic actions.

## Verification

`tests/test_identity.py`, `tests/test_policy.py`, and `tests/test_observer.py` cover
identity parsing, mention and role gates, quiet hours, probability, cooldown,
daily limits, and observation filtering.

## Extension points
