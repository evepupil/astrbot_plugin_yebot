# Message observation and context-aware group replies

- Module: group event filtering and context-aware participation gates.
- Code: `yebot/domain/identity.py`, `yebot/runtime/group_reply.py`, `yebot/runtime/group_blacklist.py`, `yebot/runtime/observer.py`, `main.py`
- Milestone: [M2](../roadmap.md#m2)
- Status: in progress
- Updated: 2026-08-12

## Responsibilities

The observer filters OneBot group messages and produces a redacted observation.
Ordinary group replies use an answerability gate: direct mentions and replies to
the bot pass immediately, while other messages with content go through a bounded
AI judgement. The judgement asks whether the available message and history can
support a useful answer, without requiring an explicit bot mention. Empty
messages and turns whose only possible output is a missing-context clarification
are denied. A final response filter also drops short replies such as “啥意思” or
“你这是在说啥”, plus model-generated no-response placeholders such as
“（没有回应，这是某人在和机器人互动）”, when the turn was not directly addressed.
This includes image-viewed notices such as “图片已查看，没有要回复的内容”. The gate
The final send filter also drops any response whose entire text is wrapped in
ASCII square brackets, such as “[本消息不需要回复]”; normal prose that only
contains a bracketed fragment is preserved. The gate never stores the raw message.

Automatic sticker reactions are started after the main Agent has produced a
non-empty group reply. A restricted agent judges the exchange, searches the
shared library once, and can send at most one matching sticker. Probability,
cooldown, quiet-hours, and daily sticker limits are no longer used.

The `blacklisted_group_ids` plugin setting is a hard group-level stop. A matching
group is stopped before context lookup, wake restoration, LLM requests, image
generation, sticker collection or reactions. Tool execution and YeBot reminder
dispatch apply the same check, so a blocked group produces no YeBot output.

## Data flow

```text
raw group event -> observe_event -> identity + mention
                         |
                         +-> context gate -> main Agent reply
                                                  |
                                                  +-> sticker judgement agent
```

`observe_only=true` keeps the plugin in observation mode. `tool_dry_run=true`
still permits decision paths while preventing real OneBot sends.

## Verification

`tests/test_identity.py`, `tests/test_group_reply.py`, `tests/test_observer.py`,
and `tests/test_group_blacklist.py` cover identity parsing, direct-address fast
paths, empty-content rejection, bounded AI judgement parsing, bracketed
meta-response filtering, observation filtering, and blacklist
normalization/matching.
