# 消息观察与低频策略

- 模块定位：在不调用模型的前提下，接收群消息、生成最小摘要并计算是否进入未来回复候选。
- 对应代码：`yebot/domain/identity.py`、`yebot/domain/policy.py`、`yebot/runtime/observer.py`
- 所属里程碑：[M2](../roadmap.md#m2)
- 当前状态：进行中
- 最近更新时间：2026-07-31

## 职责与边界

负责群消息过滤、@ 判断、角色解析、静默时段、冷却、每日上限和概率决策。默认只观察，不发消息、不调用模型、不执行工具、不保存完整原始消息。

## 结构与数据流

原始事件 -> `observe_event` -> `parse_identity` 与 `is_bot_mentioned` -> `LowFrequencyPolicy.evaluate` -> 脱敏 `Observation`。只有真实发送成功后才调用 `commit` 消耗额度。

## 关键决策

主人身份来自配置中的 QQ 号；群管理员只依据当前群 `sender.role` 判定；策略状态按群和日期保存于内存，重启后自然清空。

## 当前实现

已实现通知/请求过滤、三类角色、@ 识别、跨午夜静默判断、冷却、每日上限、概率和只观察模式。

## 验证方式

`tests/test_identity.py`、`tests/test_policy.py`、`tests/test_observer.py` 覆盖主要规则与状态转换。
