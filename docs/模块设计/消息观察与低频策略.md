# Message observation and context-aware group replies

- Module: group event filtering and context-aware participation gates.
- Code: `yebot/domain/identity.py`, `yebot/runtime/group_reply.py`, `yebot/runtime/observer.py`, `main.py`
- Milestone: [M2](../roadmap.md#m2)
- Status: in progress
- Updated: 2026-08-11

## Responsibilities

The observer filters OneBot group messages and produces a redacted observation.
Ordinary group replies use a context gate: direct mentions and replies to the bot
pass immediately, while other messages with content go through a bounded AI
judgement. Empty or contextless messages are denied without generating a reply.
The gate never stores the raw message.

Automatic sticker reactions are started after the main Agent has produced a
non-empty group reply. A restricted agent judges the exchange, searches the
shared library once, and can send at most one matching sticker. Probability,
cooldown, quiet-hours, and daily sticker limits are no longer used.

## Data flow

```text
raw group event -> observe_event -> identity + mention
                         |
                         +-> context gate -> main Agent reply
                                                  |
                                                  +-> sticker judgement agent
```

`observe_only=true` keeps the plugin in observation mode. `tool_dry_run=true`
still permits decision paths while preventing real OneBot sends.

## Verification

`tests/test_identity.py`, `tests/test_group_reply.py`, and `tests/test_observer.py`
cover identity parsing, direct-address fast paths, empty-content rejection,
bounded AI judgement parsing, and observation filtering.
