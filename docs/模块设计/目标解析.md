# 目标解析

- 模块定位：把消息中的人名、QQ 号、回复和指代词稳定解析为当前群的唯一成员。
- 对应代码：`yebot/runtime/targeting/`、`main.py`
- 所属里程碑：[M4](../roadmap.md#m4)
- 当前状态：已完成
- 最近更新时间：2026-08-03

## 职责与边界

目标解析只做成员定位，不决定调用者有没有权限，也不执行 QQ 写入。解析出的 QQ 号必须继续通过工具网关的群作用域、角色权限、确认、额度、审计和目标保护检查。

它服务于禁言、解禁、踢人、提醒和虚构转发等“需要指定某个人”的工具。普通聊天不会因为出现名字而触发成员查询或工具调用。

## 结构与数据流

成员工具调用 -> `TargetResolver` -> 唯一 QQ 号 / 歧义 / 未命中 -> 工具网关。

优先级固定为：当前消息唯一非机器人 @ -> 被回复消息的作者 -> 已验证存在的 QQ 号 -> 当前群名片或昵称 -> “他、刚才那个人、最后说话的”等指代对应的最近非机器人、非操作者发言人。前一层已唯一命中时不会继续猜测。

## 关键决策

群名片重名、多个 @、多个回复作者都会返回歧义，不能悄悄挑选一个成员。QQ群号和昵称都要通过当前群成员列表验证，模型给出的虚构 QQ 号不会进入写工具。最近发言人只用于明确的指代词，并排除当前操作者与机器人，避免把“他”错误解析成发指令的人。

回复引用使用 OneBot `get_msg` 读取被引用消息的发送者；昵称和 QQ 号使用 `get_group_member_list` 验证；指代词使用 `get_group_msg_history` 获取最近发言人。所有这些都是只读查询，查询失败会收敛为“未命中”，不会退化为猜测写入。

## 当前实现

`TargetResolver` 返回 `TargetResolution`，其状态只有 `resolved`、`ambiguous` 和 `unresolved`。`main.py` 的成员工具允许模型传 `target`，但即使模型没有传，也会从当前用户原话中提取线索；工具函数只有拿到唯一 QQ 号才调用 `YeBot.execute_tool`。主人直达提醒还会把已解析的目标转为到期消息中的 QQ @。

`targeting/models.py` 保留候选的 QQ 号、昵称、群名片和来源，供工具返回可读的补充说明；`targeting/resolver.py` 保持 OneBot 响应解析和匹配规则可独立单测。

## 验证方式

`tests/test_targeting.py` 覆盖唯一 @、回复作者、群名片、同名歧义和最近发言人指代；`tests/test_job_intent.py` 覆盖不带 @ 的提醒目标文本。还需在真实群内验收：按名字禁言、回复某条消息后说“禁言他”、说“禁言刚才那个人”、同名成员下提示补充，以及用名字创建提醒。

## 待扩展项

后续可以加入群名片别名、跨消息明确人物关系和可配置的候选展示数量。群外成员、模糊昵称和没有上下文的代词仍必须请求用户补充。
