# 确认、审计与限额

- 模块定位：阻止高风险动作被模型直接执行，并留下最小必要的可追溯记录。
- 对应代码：预留 `yebot/runtime/guardrails/`
- 所属里程碑：[M6](../roadmap.md#m6)
- 当前状态：未开始
- 最近更新时间：2026-07-31

## 职责与边界

负责二次确认、幂等键、审计事件、频率/并发/步骤额度和超时停止。

## 结构与数据流

计划动作 -> 风险评估 -> 低风险直接执行或高风险请求确认 -> 审计 -> 工具网关 -> 结果审计。

## 关键决策

确认必须绑定用户、群、动作摘要和过期时间；审计不保存完整聊天内容和秘密。

## 当前实现

尚未开始。

## 验证方式

覆盖确认过期、确认串用、重复请求、限额耗尽、执行异常和重启恢复策略。

## 待扩展项

增加管理员审批、审计导出和异常告警。

## 改动历史

- 2026-07-31：建立确认和审计边界。
