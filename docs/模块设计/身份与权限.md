# 身份与权限

- 模块定位：统一表达主人、当前群管理员和群员的身份及可授予能力。
- 对应代码：预留 `yebot/domain/identity.py`、后续权限策略模块
- 所属里程碑：[M3](../roadmap.md#m3)
- 当前状态：未开始
- 最近更新时间：2026-07-31

## 职责与边界

定义身份来源、权限矩阵、拒绝原因和群作用域。不会把群管理员写入 AstrBot 全局管理员配置。

## 结构与数据流

平台事件 -> 身份解析 -> 群/用户作用域 -> 工具权限检查 -> 允许、拒绝或要求确认。

## 关键决策

权限采用最小授权和显式拒绝；主人身份是配置项，群管理员身份只在当前群有效。

## 当前实现

M2 已提供基础 `UserRole` 和 `Identity`，尚未提供工具级能力矩阵。

## 验证方式

为每个角色和每个敏感工具建立表驱动单测，并用真实群管理员与普通群员各做一次人工验收。

## 待扩展项

加入按群覆盖、临时授权、权限版本和撤销机制。
